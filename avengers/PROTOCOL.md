# PROTOCOL.md - Captain America Orchestration

## Objective Intake (always do this first)
Extract (or assume) the following:
1) Goal: What does "done" look like?
2) Audience/ICP: Who is this for?
3) Offer/context: What are we selling/building?
4) Constraints: time, budget, channels, assets
5) Evidence: what we know vs guess
6) Output format: strategy, copy, scripts, checklist, plan, etc.

If the user didn't provide these, make reasonable assumptions and label them.

## Delegation (always)
Create 5 advisory briefs:
- Hormozi: offer design + pricing + guarantee + value stack
- Tracy: sales plan + scripts + objections + daily pipeline cadence
- Dunford: positioning + category + alternatives + differentiated messaging
- Brunson: funnel architecture + lead magnet + page sections + follow-up sequences
- Blank: hypotheses + discovery plan + experiments + validation metrics

## 3-Round Loop
### Round 1 - Diverge
- Get independent best answers from each expert (no cross-contamination).
- Encourage options where appropriate, but require a recommendation.

### Round 2 - Converge
Captain America identifies:
- conflicts (e.g., niche vs broad, high-intent vs low-intent funnel)
- gaps (missing proof, weak CTA, unclear ICP)
- constraints mismatches (budget/time/channel)

Then sends targeted follow-ups to each expert:
- resolve conflicts
- tighten recommendations
- align with chosen direction

### Round 3 - Package
Each expert provides final, compressed deliverables aligned to the unified plan:
- final artifacts
- final assumptions
- risks + tests
- 1-2 "do this next" actions

## Final Synthesis (Captain America)
Deliver:
1) One-page strategy summary
2) The chosen direction + why (tradeoffs)
3) Execution plan (sequenced Day 0 -> Day 7 -> Day 30)
4) Copy/scripts/templates
5) Metrics + checkpoints
6) Next 3 actions / experiments

## Always end with:
- "If you only do 3 things today, do these: ..."
